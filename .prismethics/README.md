# Repository-owned PrismEthics orientation

`repo-manifest.json` is this repository's owner-attested statement of role,
authority, non-authority, contracts, and canonical entrypoints.

Its `observed_commit` is the immutable candidate-branch basis immediately before
this manifest transaction. GitHub supplies the containing commit and current head;
those identities are recorded by Project Web receipts and projections.

This repository owns the visible Conversational Workbench pilot contract and
site source. The governing experience is "structured inside; conversational
outside": one composer, ordinary conversation, optional prose perspectives,
research and artifacts that emerge from the work, quiet re-entry, and Human
Authority at consequential forks.

The site implements only a candidate site-side turn seam, a stateless provider
adapter, and device-local recent-work convenience. It does not select or rebind
the governed runtime, execute exact Frame Library procedures, establish canonical
Work Object persistence, or close the Product Minimal Viable Step (MVS).

Read `docs/CONVERSATIONAL_WORKBENCH_PILOT_CONTRACT_v0_1.md` for the visible
experience and `.prismethics/change-events/EVT-SITE-CONVERSATIONAL-WORKBENCH-ARCHITECTURE-V0-1-20260821.json`
