# Repository-owned PrismEthics orientation

`repo-manifest.json` is this repository's owner-attested statement of role, authority,
non-authority, contracts, and canonical entrypoints.

Its `observed_commit` is the immutable candidate-branch basis immediately before
this manifest transaction. A file cannot contain the SHA of the commit that contains
itself. GitHub supplies the containing commit and current branch/default head; Project
Web receipts and projections record those identities externally.

This repository owns the public site shell, the conversational Workbench pilot
experience contract and source, its site-side candidate turn boundary, its stateless
provider adapter, browser-local recent-work presentation, site build and hosting
configuration, and site-owned trust-boundary presentation.

`docs/CONVERSATIONAL_WORKBENCH_PILOT_CONTRACT_v0_1.md` is authoritative for the
visible pilot experience. Its governing sentence is "structured inside;
conversational outside": one composer, ordinary conversation, optional prose
perspectives, research and artifacts that emerge from the work, quiet re-entry, and
Human Authority at consequential forks. It supersedes form-, checklist-, and
frame-administration directions for this pilot without closing or merging the drafts
that contain them.

The repository does not select, admit, or rebind the governed runtime and does not
prove a deployment or domain, accounts or tenant isolation, cloud persistence,
production security or deletion, provider billing authority, cross-model continuity,
Product MVS closure, or canonical promotion. A configured site-side model exchange
is a candidate contribution boundary, not canonical Work Object persistence.

The repository preserves, but does not claim conformance to, D-89's candidate
modular-monolith direction: `SessionRuntime`, `FrameRuntimePort`, `ModelRuntimePort`,
`WorkObjectStore`, `ProjectionEngine`, and `Authorization`. It also preserves the
admitted Integrated Runtime binding as cross-repository architecture evidence:
event-derived state, permission-filtered ContextPackages, two-phase checkpoint/close,
exact-owner dispatch, provenance, Quiet Intelligence, and hard Human Authority stops.

For this slice, bounded conversation context is product-owned and provider calls are
stateless (`store: false`); provider response state is not continuity. Prose
perspectives are model synthesis rather than Frame Library receipts. Provider-assisted
web search is not the governed research-owner route. Exact Frame Library execution,
canonical Work Object storage and authorization, full Integrated Runtime conformance,
paid/live proof, authentication, and deployment remain explicit holds.
