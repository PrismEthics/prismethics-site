# Repository-owned PrismEthics orientation

`repo-manifest.json` is this repository's owner-attested statement of role, authority,
non-authority, contracts, and canonical entrypoints.

Its `observed_commit` is the immutable basis commit immediately before the manifest
transaction. The containing commit and current branch/default head are observed from
GitHub and recorded externally by consumer receipts and projections; they are never
recursively written into the manifest.

This repository owns the public site shell, browser-local Workbench source, site build
and hosting configuration, and site-owned trust-boundary presentation. This manifest
does not connect or select a governed runtime and does not prove deployment/domain,
accounts, cloud persistence, security, pricing, usage, billing, provider execution, or
Product MVS closure.
